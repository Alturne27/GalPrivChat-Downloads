Installation

Android
  1. Téléchargez l'APK puis ouvrez-le depuis la notification ou le dossier Téléchargements.
  2. Si Android le demande, autorisez votre navigateur à installer des applications inconnues (Paramètres → Sécurité).
  3. Appuyez sur Installer.

Vous aviez une version antérieure à 1.1.0 ? Elle était signée différemment : Android refusera la mise à jour. Notez d'abord votre phrase de récupération (Paramètres de l'application), désinstallez l'ancienne version, puis installez celle-ci et restaurez votre compte. À partir de la 1.1.0, les mises à jour s'installent normalement par-dessus.

Windows
  1. Téléchargez et lancez l'installateur.
  2. Si Windows affiche « Windows a protégé votre ordinateur » (éditeur non reconnu), cliquez sur Informations complémentaires puis Exécuter quand même.
  3. Les mises à jour s'installent par-dessus la version existante.
Vérifier l'intégrité du fichier

Comparez l'empreinte SHA-256 affichée sous chaque bouton avec celle du fichier téléchargé :

Windows (PowerShell) : Get-FileHash -Algorithm SHA256 .\NomDuFichier
Linux / macOS :        sha256sum NomDuFichier

Toutes les empreintes sont aussi publiées dans SHA256SUMS.txt.
